# Regras para agentes neste repositório

- Tudo aqui é público. Nunca adicione CNPJ, CPF, nomes de clientes, valores reais, senhas ou tokens.
- Exemplos só com dados fictícios em `exemplos/`.
- Scripts: só biblioteca padrão do Python 3.10+, valores em `Decimal`, saída em padrão brasileiro (R$ 1.234,56).
- Toda skill termina dizendo **o que foi conferido**. Total sem conferência não é entrega.
- Agente nunca executa pagamento, transferência nem digita senha/captcha.
- Testar antes de commitar: `bash scripts/testar.sh`.
